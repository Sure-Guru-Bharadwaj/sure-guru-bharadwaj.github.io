# Professional Portfolio - Sure Guru Bharadwaj

A responsive, high-performance web portfolio crafted specifically for **Sure Guru Bharadwaj**, an Electronics & Communication Engineering undergraduate specializing in **VLSI Design, FPGA Prototyping, and Embedded Systems**.

## 🚀 Features Included
- **Semiconductor & Cyber-Tech Design Theme**: Dark slate palette with electric cyan accents, subtle PCB traces, and floating animated silicon chip component.
- **Dynamic Interactive Canvas**: Interactive particle and circuit-trace mesh background reacting to cursor movement.
- **Dynamic Typewriter Header**: Rotating engineering focus highlights in the hero section.
- **Animated Metrics & Statistics Strip**: Live counters for GPA (6.81 VFSTR), 100% Class X score, projects built, and platforms mastered.
- **Categorized Skills Matrix**: 
  - Languages (Verilog, C, Embedded C, Python, MATLAB)
  - EDA & Simulation Tools (Xilinx Vivado, Cadence Virtuoso, MATLAB Simulink)
  - Engineering Domains (Digital Design, VLSI, FPGA, Embedded Systems)
  - Hardware Platforms (Raspberry Pi, ESP32, STM32, Arduino Uno/Mega/Nano, NodeMCU)
- **Interactive Project Showcase**:
  - Filterable by categories (*All*, *FPGA & VLSI*, *Embedded & Automotive*, *Smart IoT*, *Software*)
  - Detailed architectural popup modals for each project (AES FPGA Image Encryption, CAN-IoT EV Battery Monitor, GUI Smart Irrigation, Weather Station, Offline Chatbot).
- **Academic Timeline & Leadership**:
  - Education history (VFSTR B.Tech ECE, Sri Chaitanya, Kanna English Medium School).
  - Andhra Pradesh Space Tech Summit Core Coordinator role.
- **Direct Contact System**:
  - Direct mailto integration and phone link.
  - One-click copy email button with toast feedback.
  - Interactive contact inquiry form.
- **Dark / Light Theme Toggle**: Persistent via `localStorage`.
- **Fully Responsive**: Optimized for ultra-wide monitors, laptops, tablets, and smartphones.

## 🌐 How to Run Locally
1. Double click on `index.html` to open directly in any browser (Chrome, Edge, Firefox, Safari).
2. Or run a lightweight local HTTP server:
   ```powershell
   npx serve .
   # or
   python -m http.server 8000
   ```
   Then open `http://localhost:8000`.

## 🚢 Free 1-Click Deployment
- **GitHub Pages**: Push this directory to a repository named `sure-guru-bharadwaj.github.io` or enable GitHub Pages in Settings -> Pages.
- **Vercel / Netlify**: Drag and drop the `bharadwaj-portfolio` folder into [Netlify Drop](https://app.netlify.com/drop) or import from GitHub on Vercel.
